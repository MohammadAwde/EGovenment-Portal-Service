## Button States

### SUBMIT BUTTON - THREE STATES

#### State 1: No Service Selected
```
[Submit Request] ? Enabled but gray (needs service)
Tooltip: "Select a service first"
```

#### State 2: Service Selected, Missing Documents
```
[Submit Request] ? DISABLED (grayed out, can't click)
Tooltip: "Please upload all required documents"
```

#### State 3: All Documents Uploaded
```
[Submit Request] ? ENABLED (green/bold, clickable)
Tooltip: ""
```

## Form Behavior

### SAVE AS DRAFT
- **Always works** (no document validation)
- Does not require mandatory documents
- Drafts auto-save every 15 seconds
- User can return later to complete

### SUBMIT REQUEST
- **Only works** when ALL mandatory documents uploaded
- Submit button physically disabled if incomplete
- Server-side validation also checks
- Returns helpful error if somehow submitted incomplete
